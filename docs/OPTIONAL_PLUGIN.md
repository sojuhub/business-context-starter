# Optional native packaging

The default path for Codex, Claude Code, Hermes and OpenClaw is the same:
read the repository and follow START_HERE.md. No native plugin install is required.

This package also retains Codex and Claude plugin metadata for developers.
Native plugin loading remains unverified. Hermes and OpenClaw do not have native
plugin manifests in this package; use the shared instruction route.

If testing native loading, inspect the installed host's current supported method,
use its normal permissions, and verify actual loading. Registration, a manifest or
a discovered skill is not proof of onboarding behavior. Avoid duplicate copies.

Business data stays in the existing approved private workspace, not plugin caches.
Do not rewrite global settings, generated memory or unrelated project instructions.
Any private account connection and any external action needs its own scoped approval.
